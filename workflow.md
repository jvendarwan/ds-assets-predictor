3. Typical Enterprise ML Workflow & Tech Stack
   Workflow/Pipeline:
   Data Ingestion:
   Collect and store raw data (databases, data lakes, cloud storage).
   Data Processing/Feature Engineering:
   Clean, transform, and engineer features (ETL pipelines, batch jobs).
   EDA & Visualization:
   Understand data, spot issues, and generate insights (notebooks, scripts).
   Model Development:
   Train and validate models (modular Python code, version control).
   Experiment Tracking:
   Log parameters, metrics, and artifacts (MLflow, wandb).
   Model Evaluation:
   Assess model performance (metrics, plots, validation).
   Model Packaging:
   Serialize models (pickle, joblib, ONNX).
   Deployment:
   Serve models via APIs (Flask, FastAPI, Docker, cloud services).
   Monitoring:
   Track model performance in production (drift, latency, errors).
   Automation:
   Orchestrate with pipelines (Airflow, Kubeflow, Prefect).
